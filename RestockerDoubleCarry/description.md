# Restocker Double Carry

Experienced restockers (level 10 and up) carry two boxes per trip.

## Features

- Works both for restocking shelves and for taking delivered boxes to storage.
- A trip can be two restocks, two boxes for storage, or one of each.
- The second box is shown stacked on top of the first.
- Fewer trips, so shelves get filled faster.

## How it works

The restocker picks up a second box before leaving. It deals first with the box whose destination is closer. When it reaches a shelf with two boxes, it puts one on the floor beside it, restocks from the other, then goes back for the floor box. Other restockers leave that box alone.

## Multiplayer

Only the host needs the mod, because restockers run on the host. Guests without it see the two boxes in the same spot, so it looks like one.

## Compatibility

Works with MoreEmployees.

## Installation

Requires BepInEx 6 (IL2CPP). Copy `RestockerDoubleCarry.dll` into `BepInEx/plugins/`.
