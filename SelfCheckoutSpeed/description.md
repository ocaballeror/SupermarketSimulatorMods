[size=6][b]Self Checkout Speed[/b][/size]

Checkouts scan customers' items faster: 2x by default, up to 10x.

[quote][b]MULTIPLAYER: INSTALL IT ON THE HOST AND ON EVERY GUEST.[/b] The host is required. Guests without it will see customers leave before their items are scanned at self checkouts.[/quote]

[size=5][b]Features[/b][/size]

[list]
[*]Speeds up scanning at self checkout machines.
[*]Speeds up customer helpers who scan for a customer.
[*]Speeds up cashier employees at regular checkouts.
[*]Payment is not sped up, so it takes as long as in the normal game.
[*]You can use decimals, for example 1.5x.
[/list]

[size=5][b]Multiplayer[/b][/size]

[b]Host: required. Guests: install it too[/b] (strongly recommended), so self checkouts look right on their screen. A guest follows the host's speed automatically.

[size=5][b]Settings[/b][/size]

You can change the speed multiplier.

[size=5][b]Installation[/b][/size]

Requires BepInEx 6 (IL2CPP). Copy [i]SelfCheckoutSpeed.dll[/i] into [i]BepInEx/plugins/[/i].
