# Self Checkout Speed

Checkouts scan customers' items faster: 2x by default, up to 10x.

## Features

- Speeds up scanning at self checkout machines.
- Speeds up customer helpers who scan for a customer.
- Speeds up cashier employees at regular checkouts.
- Payment is not sped up, so it takes as long as in the normal game.
- You can use decimals, for example 1.5x.

## Multiplayer

The host needs the mod. Guests are strongly recommended to install it too, so self checkouts look right on their screen. A guest follows the host's speed automatically.

## Settings

You can change the speed multiplier.

## Installation

Requires BepInEx 6 (IL2CPP). Copy `SelfCheckoutSpeed.dll` into `BepInEx/plugins/`.
