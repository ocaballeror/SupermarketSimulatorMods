# Extra Computers

Buy more computers for your store.

> **MULTIPLAYER: THE HOST AND EVERY GUEST MUST INSTALL THIS MOD.** Everyone in the session needs it, otherwise the computers won't work for them and they will get errors.

## Features

- A new **Computer** in the furniture shop for $1000. Buy as many as you like.
- Each one works like the store's own computer: shop, pricing, hiring, management, everything.
- Each computer remembers which apps and tabs you left open on it.
- In multiplayer, every player has their own screen, so two players can work on two computers at once.
- Move them, box them up and save them like any other furniture.

## How it works

Buy the computer in the furniture shop, unbox it and place it anywhere. Only one player can use a given computer at a time.

## Multiplayer

**Required on the host AND on every guest.** By default, the computer is hidden in the shop while a player without the mod is in the room, to protect them from errors.

## Important

Before you remove the mod, box up every placed computer. Otherwise the game may fail to load part of your store.

## Installation

Requires BepInEx 6 (IL2CPP). Copy `ExtraComputers.dll` into `BepInEx/plugins/`.
